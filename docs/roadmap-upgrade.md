# RareGuard 提升改造计划（三阶段）

对应方案书 [product-proposal.md](product-proposal.md) §六「赛后计划」。本文是**工程开工清单**，不改规则阈值、不改 `mas_score`、不把 API 默认 `profile` 从 `standard` 改成 `early`。官方 PRD 对照与延期理由见 [prd-v1-gap-checklist.md](prd-v1-gap-checklist.md)。

**总策略**：加强**规则主权可复验**（确定性判险 + 合成留出门禁 + 文案不越线），**不做** L3 独立坐诊、**不做**权重级自我进化、**不做** FHIR/DICOM 全量互通。

---

## 0. 自主性 L1 硬边界（与校验管道不要混称）

| 名称 | 含义 | 允许出现的语境 | 禁止 |
|---|---|---|---|
| **自主性 L1** | 医学智能体光谱上的停线：判险主权在规则引擎，LLM 只叙述 | README / 方案书光谱节、家庭端 `autonomy_level: "L1"` + `decision_owner: "rules_engine"` | 用它指输入净化、提示注入拦截 |
| **V1 / input_guard** | 六层校验里的**输入净化**（提示注入/角色覆盖/超长截断） | `verification/pipeline.py` 注释与对外说明 | 写成「产品已经是 L1 所以会拦注入」或反过来 |
| **校验管道 L3/L4/L5/L6** | 事实接地 / 医疗护栏 / PHI / 审计 | 护栏与 fail-closed 叙事 | 写成自主性光谱的 L3（独立坐诊） |

接口**保留** `autonomy_level: "L1"` 与 `decision_owner`。审计 JSON 里管道层键名仍可为 `L1`（历史兼容，避免大范围改测试断言）；语义上那是 **V1**，不是自主性 L1。

## 1. 优先级与不做清单

| 优先级 | 含义 | 本仓库落点 |
|---|---|---|
| **P0** | 赛前必须：证据不吹牛、演示入口不歧义、评委 10 分钟能看懂档位 | 阶段 A |
| **P1** | 有真实样例/共创反馈才做：OCR 真值、文案与权重评审 | 阶段 B |
| **P2** | 赛后孵化：同源复用、LIS；仍停在自主性 L1 | 阶段 C |

**不做（全阶段）**

- 不改 R-A/R-B/R-C / 2016 规则数值阈值「凑绿」
- 不改 `mas_score` 权重公式（待医师共创后再开独立任务）
- 不把 `assess_patient` / `/api/home/risk` 默认 `profile` 改成 `early`
- 不上 L3 坐诊、不上在线改规则/改模型权重的「自我进化」
- 不上 FHIR/DICOM 全量、不删 `orchestrator` 预问诊代码（只隔离入口）

## 2. 阶段 A（P0 · 本轮开工）

**开工顺序：A1 → A3 → A2 → A4 → A6。**

| 编号 | 内容 | 验收 |
|---|---|---|
| **A1 证据口径** | 路演/彩排/方案书§四/README 评测段：固定句「**合成留出是回归门禁，不是临床金标**」；数字旁标合成规模（**N=6**：2 例 MAS 前驱 + 4 例正常对照，以 `synth/generate_dataset.py` 为准）；共创用**进行时**，不填假人数；禁止把 OCR≥98% / 召回 100% 写成已对**真实患儿**验证 | 上述文档无「临床金标」「已访谈 N 人」假数；OCR≥98% 明确仅合成化验单 |
| **A3 预问诊入口隔离** | README/启动命令只留家庭端 `python -m rareguard.api.home_server`；`app.py` 与 `index.html` / `doctor.html` / `nurse.html` 标明「基座遗留，非参赛主路径」或从演示入口断开 | 参赛启动路径唯一；**不删** `orchestrator` |
| **A2 尽早叙事（不改 API 默认）** | 家庭端早提示开关：当前档位名称 + 「只升不降」；路演分镜让评委 10 分钟内看见档位；未开 early 的严格档**不得**说成 PRINTO | 勾选才走 `profile=early`；默认仍 HLH-2004 严格档 |
| **A4 L1 术语拆分** | 管道输入净化对外称 V1/`input_guard`；产品文档「自主性 L1」只出现在光谱 / home meta | 接口字段不改；测试断言名不大改 |
| **A6 CI 门禁（可选）** | `.github/workflows/gates.yml`：`pytest` 跳过 `real_api` + 离线 `run_all_gates.py` | 无密钥时 real-smoke skip、离线步 fail=阻断 |

**阶段 A 验收总闸**：不改判险逻辑；`python -m pytest -q`（`real_api` 默认跳过）绿。

## 4. 阶段 C（P2 · 赛后，本轮不做）

| 编号 | 内容 | 边界 |
|---|---|---|
| C1 | 患者共创反馈 → 规则/文案 v2（仍规则主权） | 仍自主性 L1 |
| C2 | 家庭端作为基层 AI 问诊平台的**重症转诊前哨**同源复用 | 预问诊基座可再启用，不与赛题主路径混淆 |
| C3 | 风湿科随访 + **对接院内 LIS 取化验**（点对点，非 FHIR 全量） | 不做 FHIR/DICOM 全家桶 |
| C4 | 持续开源接力 | 不做 L3、不做权重级自我进化 |

方案书 §六一句话仍有效：共创 → 取值/权重 v2 → 基层问诊同源复用 → 开源接力。细节以本文为准。
