# RareGuard 产品方案（赛题 04 · 提交版 v1.0 · 2026-09-22）

**赛题**：sJIA 并发症预警平台（对应官方仓库 sjia-mas-early-warning-platform / 赛题群「sJIA并发症预警平台」）
**团队**：1 人 + AI 结对开发（已按规则准备签署 CLA 与患者数据保密协议）
**开源**：Apache-2.0，全部可公开成果（代码/文档/评测/测试记录）赛期内持续上传 GitHub，赛后继续维护

---

## 一、我们解决什么问题

至少 **7% 的 sJIA 患儿**会在病程中出现 MAS 这一最凶险并发症，队列**病死率可达 8%**（数据引自 sJIA 守护者联盟《研发方案 v1.0》）。MAS 早期表现与 sJIA 活动期难以区分，院外/home 场景完全没有动态预警手段——等指标凑齐诊断标准再干预，往往已错过时机。

**RareGuard 把「盯指标趋势」这件事交到家长手里**：家长每天 30 秒打卡、拍一张化验单，系统在指标达到危险动态之前亮灯，并生成能直接带给急诊医生的一页纸。

## 二、产品形态（家庭端 Web PWA，四屏）

1. **仪表盘**：红绿灯 + MAS 风险分（0–100）+ 90 天趋势曲线
2. **拍照录入**：化验单 OCR 双通道解析，逐字段确认后入库（识别不了就手工录）
3. **每日打卡**：体温 + 症状勾选，接上院外趋势断层
4. **预警详情**：红色预警强弹窗 + 急诊准备清单 + **可打印的就诊一页纸**（趋势图、异常化验标红表、免责声明）

关键红线：**风险结论 100% 出自可审计的确定性规则引擎，AI 大模型只把结论翻译成家长看得懂的话**——断网照常出预警（现场演示全程可拔网线）。

### 2.1 自主性定位：L1 辅助预警（非 L3）

按医学智能体光谱，RareGuard **刻意停在 L1 辅助预警**：规则引擎拥有判险主权（`decision_owner: rules_engine`），LLM 仅叙述；用确定性规则与长尾/MAS 前驱留出回归门禁，对抗「罕见病表型被通用模型抹除」。**不做** L3 独立坐诊、**不做**权重级自我进化、**不做** FHIR/DICOM 全量互通。该表述借用 arXiv:2607.11175（Zhu et al.）综述中的光谱作定位解读，并非声称已实现该文自我进化架构。

## 三、与官方研发方案 v1.0 的逐条对齐

| 官方框架要求 | RareGuard 现状 |
|---|---|
| 静态监测单次指标 | ✅ R-A 绝对阈值规则（铁蛋白/血小板/纤维蛋白原/转氨酶/甘油三酯/体温/血沉-CRP 分离） |
| 动态监测指标变化 | ✅ R-B 趋势规则（爬升速率、较基线下降等） |
| 报警灵敏度可设置 | ✅ 双档：HLH-2004 严格档（默认）+ **2016 PRINTO/ACR/EULAR 敏感档**（官方主流标准：发热+铁蛋白>684+≥2 项次要指标），灵敏度旋钮 `min_criteria` 可调 |
| 核心指标 / 一般指标分层 | ✅ 2016 档内已分层（核心：血小板、AST；一般：甘油三酯、纤维蛋白原），命中证据带 `met_core/met_general` |
| 指标权重可设置 | 🔜 当前评分权重为固定档位（8 项 ×12.5 简化自 HLH-2004），**权重配置化计划共创期与风湿科医师共同定档** |
| 连续预警、动态观察 | ✅ 逐日重算 + 90 天风险分曲线 + 提前量实测（见下） |

PRD 条款级「已实现 / 部分 / 明确延期」（含 MS、权重、医生端、查体项）见 [prd-v1-gap-checklist.md](prd-v1-gap-checklist.md)。方案书本节不扩写。

## 四、已经验证了什么（长尾留出回归；一键自检 `python scripts/run_all_gates.py`）

**合成留出是回归门禁，不是临床金标。** 评测叙事是罕见表型 / MAS 前驱的**合成留出回归**：`synth/generate_dataset.py`（seed=42）生成可复现集 → `evals/gate_rareguard.py` 卡召回/提前量/误报 → `scripts/run_all_gates.py` 编排五道门禁；**任一 fail = 发布阻断**（不改阈值凑绿）。下列数字均来自该合成集，**尚未对真实患儿临床验证**。

- **召回率 100%**、预警平均提前 **192 小时**（门禁要求 ≥48h）、**误报 0 次**（门禁 ≤1 次/患者·月）——合成留出集 **N=6**（2 例 MAS 前驱 + 4 例正常对照，以仓库 `synth/generate_dataset.py` 为准）
- **红线对抗 0 违规**：越界输出（确诊话术/剂量/停药建议）被校验管道护栏拦截并回退模板（管道层，非自主性光谱）
- OCR 字段准确率 ≥98% **仅针对合成化验单**，不是真实患儿报告上的已验证指标；真实脱敏样例评测脚手架已就绪，**待联盟供样即出报告**
- 自动化测试 + 断网全链路 E2E 绿；离线演示包预跑脚本一键生成
- 规则取值全部登记文献出处（docs/references.md），含 2016 PRINTO（Ravelli 2016）、HLH-2004、中国专家共识簇

截图取证：`docs/assets/01-red-alert.png`（红色预警+急诊清单）、`docs/assets/02-one-pager.png`（就诊一页纸）。
