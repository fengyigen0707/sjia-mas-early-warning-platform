## 3. 检查清单

### 3.1 已实现（路演可勾、须带边界）

- [x] L1 辅助预警：规则主权，不替代诊疗
- [x] 单次录入 → 静态（R-A）
- [x] 两次及以上 → 静态 + 动态（R-A + R-B，含静态正常/动态异常）
- [x] HLH-2004 风味严格档为 **API 默认** `profile=standard`
- [x] 2016 PRINTO 敏感档可经家庭端「早提示」/`profile=early` 叠加，只升不降
- [x] `min_criteria` 灵敏度旋钮（2016 次要项条数）
- [x] 2016 档核心/一般分层（`met_core` / `met_general`）
- [x] 指标：发热、铁蛋白、血小板、纤维蛋白原、甘油三酯（家庭可及化验 + 打卡）
- [x] AST 进入 2016 敏感档核心项（录入/归一化支持）
- [x] 家庭端四屏 + 就诊一页纸（给地方医生的当面交接物）
- [x] 取值文献可查（`docs/references.md`），规则不经 LLM

### 3.2 部分实现（说「有」，同时说「缺哪一截」）

- [ ] **PRINTO 是官方主流，但不是本仓库默认档** — 默认 HLH 严格档；评委没看到开关就说 PRINTO 算口径错误（路线图 A2）
- [ ] **血细胞** — 落地的是 PLT，不是全套三系
- [ ] **肝酶** — 严格档 ALT，敏感档 AST
- [ ] **灵敏度** — 有旋钮，但不是官方图4 三档报警幅度（PLT↓20–40% / SF↑80–200% / ALT↑30–40%）；R-B 步幅更灵敏、性质不同，评审前不改（references #8 vs #18）
- [ ] **出血 / 关节痛** — 打卡可记，不进入 MS、不做分类诊断
- [ ] **地方医生** — 有一页纸，无 MAS 医生工作台

### 3.3 明确延期（不要演示成已有功能）

| 延期项 | 为什么现在不做 |
|---|---|
| **MS 评分**（表6，MS≥−2.1） | ① 单位与 0/1 取值未核《儿童风湿病学》第 8 版原文，系数对单位敏感；② 适用域是**已发热的 sJIA**，不是普通筛查；③ 路线图 B3：医师评审前 **零改 `mas_score`**。 |
| **指标权重可设置** | 现 8×12.5 硬编码。做成可配等于赛期改判险；须共创 + 登记 references 后再独立 PR。 |
| **默认档改为 PRINTO** | 官方叙事主流是 2016；工程默认保持 `standard`，避免合成门禁与特异性回退。尽早提示走开关，不改 API 默认。 |
| **独立医生端** | `doctor.html` / `app.py` 是基座预问诊遗留，已隔离入口。赛题主路径只有家庭端；医生侧赛后 C2/C3（随访 + 点对点 LIS），不是本周补页面。 |
| **脾大必填** | 体格检查，家庭不可得（references #14）。强填制造假阴性/假阳性，且滑向疾病分类。 |
| **CNS / 出血现象 / 关节炎入 MS** | 同属查体或鉴别项；家庭 VAS ≠ 公式变量。接上去等于未评审实现 MS。 |
| **LDH 入规则** | 主路径无该码；绑定未实现的 MS。OCR 本期不加字段（与 official-plan-tables「本期不改 OCR」一致）。 |
| **PRINTO 2019 / ILAR sJIA 分类** | 家庭端不做疾病分类（L1 红线）。表1 只用于科普/访谈背景。 |
| **按动态项数分轻/中/重** | 与现红黄绿灯正交；改分级会动文案与门禁叙事。共创候选，不是静默实现。 |
| **对齐官方报警幅度并改 R-B** | 评审前不改阈值。官方幅度作对照基准，写在 official-plan-tables，不写进代码。 |
| **真实患儿临床验证** | 仅有合成 N=6 回归门禁。OCR≥98%、召回 100% **只对合成集**。真实脱敏样例与医师评审属阶段 B。 |
| **L3 坐诊 / 权重自我进化 / FHIR 全量** | 产品红线，全阶段不做（路线图「不做」清单）。 |
