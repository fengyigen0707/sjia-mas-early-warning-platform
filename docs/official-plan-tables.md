## 表1 sJIA 分类标准：ILAR 2001 vs PRINTO 2019

| | ILAR 2001 | PRINTO 2019 |
|---|---|---|
| 诊断 | 不明原因关节炎，发病年龄 <16 岁，病程 ≥6 周；sJIA 亚型：关节炎 + 弛张热 ≥2 周 + 以下至少 1 项：①一过性（急性）非固定性红斑样皮疹 ②全身淋巴结肿大 ③肝脾肿大 ④浆膜炎（读图，括注细节模糊） | 不明原因发热，推测与全身炎症相关，每日发热 ≥2 周 + 以下至少 2 项：①一过性、非固定性红斑样皮疹 ②全身淋巴结肿大 ③肝脾肿大 ④浆膜炎（读图，括注细节模糊） |
| 排除 | 4 条（读图，部分模糊）：①本人或一级亲属银屑病史 ②≥6 岁男性 HLA-B27 相关疾病 ③关节炎伴脊柱关节病特征 ④类风湿因子相关（模糊） | 表内未见明确排除标准（待核原文） |

注：ILAR=国际风湿病联盟；PRINTO=儿童风湿病国际试验组织（读图）。

**登记要点**：PRINTO 2019 把 sJIA 判定从「关节炎必需」改为「发热 + 4 项中 ≥2 项」，关节炎非必需——家庭端指标预警不依赖关节查体，与该口径一致。用于科普/鉴别叙事与访谈背景；**家庭端不做疾病分类**（L1 红线）。

## 表6 MS 疾病活动度评分公式（官方「其他诊断标准」之一）

```
MS = 2.44×中枢神经系统受累 + 1.54×出血现象 + (−1.30)×关节炎
     + (−0.003)×血小板计数 + 0.001×乳酸脱氢酶 + (−0.004)×纤维蛋白原
     + 0.0001×铁蛋白
```

- 判定：**MS ≥ −2.1 → sJIA 合并 MAS 可能性大**（公式内不含发热：发热是病情活动的强制指标）。
- **状态：未实现，仅为登记**。实现前必须解决三点：①各变量单位与「受累=1/无=0」取值约定须从原始文献确认（表内未给单位，系数对单位敏感）；②该评分是**在发热的 sJIA 患者内部区分 MAS** 的工具，不是普通人群筛查工具；③评审前不动 `mas_score`（路线图 B3：未评审前零改权重）。定位：共创期评审的第三判据/评分展示候选。

## 图4 预警平台框架思维导图（官方；部分字迹模糊）

```
MAS预警平台
├─ 静态：单次单次指标 → 输入相关指标数值即可得出评分 → 未达MAS / 达到MAS
├─ 动态：监测指标动态变化
│   ├─ 设置报警灵敏度档位（读图，三档参考幅度）：
│   │   档1（名称模糊，似「灵敏」）：血小板下降20%、铁蛋白上升80%、ALT升高30%
│   │   档2（似「标准」）：血小板下降20%、铁蛋白上升100%、ALT升高40%
│   │   档3（名称模糊，似「保守」）：血小板下降40%、铁蛋白上升200%、ALT升高40%
│   └─ 报警管理：可设置核心指标和一般指标；按动态变化项数分级（读图）：
│       轻度（首字模糊）＝1项或以上发生动态变化 / 中度＝2项或以上 / 重度＝3项或以上
└─ 预警平台静态与动态结合
    ├─ 只输入一次数据：静态监测
    └─ 输入2次及以上：静态+动态监测，组合情形（2×2，图未标各组合处置）：
        静态正常+动态正常 / 静态正常+动态异常 / 静态异常+动态正常（模糊） / 静态异常+动态异常
```

### 与仓库现状对照（不改代码，共创评审素材）

1. **核心/一般指标分层报警** ↔ 已实现（2016 档 `met_core`/`met_general` 证据分层），官方图4 直接印证该设计，references #13 对齐度进一步提高。
2. **灵敏度档位的官方参考幅度**（PLT↓20–40%、铁蛋白↑80–200%、ALT↑30–40%）与本仓库 R-B 趋势参数（references #8：CRP+15%/级、PLT−8%/级、FIB−10%/级）**性质不同**：官方是「报警触发幅度」档位，我方是「抗基线噪声最小步幅」。官方幅度数量级更大，说明我方趋势触发更早（更灵敏）。**共创评审 R-B 参数时，官方档位应作为对照基准之一**；评审前不改阈值。档位名称与完整指标覆盖（图上仅见 PLT/铁蛋白/ALT 三项）待向需求方确认。
3. **轻/中/重按动态变化项数分级** ↔ 我方红/黄灯按阈值档位决定，未按「命中项数」分级；可作为报警文案分级的共创候选（不是缺口，是口径差异）。
4. **静态+动态 2×2 组合** ↔ 已实现（R-A+R-B 并行评估）；其中「静态正常+动态异常」正是官方框架点名的早期场景，与 `profile=early` 敏感档 + R-B 趋势规则的存在理由一致——**路演可引官方图4 支撑「为什么要趋势+敏感档」的叙事**。
5. **铁蛋白动态口径（↑80–200%）**与 R-B「较基线上升」一致：官方动态监测看上升幅度而非绝对值，印证趋势规则设计。
